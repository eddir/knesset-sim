# Симулятор Кнессета · 2026

Тест про выборы в 26-й Кнессет 27 октября 2026 года. Интерфейс на русском, английском и иврите: переключатель RU / EN / עב в шапке. Иврит открывает страницу справа налево. Вопросы разбиты на разделы: после каждого раздела зал показывает, сколько мест уже разыграно. В конце подробный отчёт: 120 мандатов, барьер 3,25%, коалиции, законопроекты и каждый ответ.

Позиции партий - редакционная оценка по публичным заявлениям осени 2026 года, не официальный калькулятор ЦИК и не прогноз явки.

## GitHub Pages

Сайт статический. В репозитории уже есть workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml): на каждый push в `main` он гоняет тесты, собирает `dist` и публикует Pages.

1. Создайте репозиторий на GitHub и запушьте туда эту ветку `main`.
2. Откройте **Settings → Pages → Build and deployment**.
3. В поле **Source** выберите **GitHub Actions**.
4. Дождитесь зелёного workflow **Deploy GitHub Pages**. Адрес будет вида `https://<пользователь>.github.io/<репозиторий>/`.

На бесплатном плане Pages работает для публичного репозитория. Если сайт открывается без стилей, проверьте, что источник сборки именно GitHub Actions, а не ветка `main` напрямую: Vite кладёт файлы в `dist`, не в корень.

Свои ответы хранятся только в браузере.
